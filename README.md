# StudySync – B.Tech Academic Hub 📚

A modern, responsive, clean-white themed academic web application designed specifically for B.Tech engineering students.

---

## 🌟 Key Features

1. **Clean White Modern Theme (No Gradients):**
   - Clean, high-readability design crafted for long study sessions.
   - Professional borders, soft shadows, and responsive layout for mobile and desktop.

2. **Top Quick Module Ribbon:**
   - Prominently positioned right under the header for 1-click access:
     - 📄 Notes Hub
     - 📝 University PYQs
     - 🎯 Mock Tests
     - ⏱ Study Timer
     - 📤 Upload Notes
     - 📂 My Uploads

3. **Secure Authentication & Registration:**
   - Empty input fields on sign-in (no prefilled credentials).
   - Validated student registration storing data safely in client storage.
   - **Main Administrator:** Priya Singh (`admin@studysync.edu` / `StudySync@Admin2026`).

4. **Main Admin Control Center (Priya Singh):**
   - Complete directory showing every registered user (Name, Email, Branch, Year, Join Date, Uploads).
   - Ability to review and manage accounts.

5. **"My Uploads" Dedicated Section:**
   - Students and admin can view, review, and manage all study notes uploaded by their account in one place.

6. **Thermodynamics & Engineering Notes Hub:**
   - High-yield, authentic notes on:
     - *Thermodynamics* (Zeroth to 3rd Law, Isobaric/Isochoric/Adiabatic processes, Carnot Cycle, Rankine Steam Power Plant Cycle, Entropy, Formula table).
     - *Data Structures & Algorithms* (Arrays, Trees, Graphs, Sorting algorithms).
     - *DBMS* (ER models, 1NF to BCNF Normalization, ACID properties).
     - *Signals & Systems* (Fourier Transform, Nyquist rate, Sampling).
     - *Engineering Mathematics* & *Structural Analysis*.
   - Search by topic, subject, or branch filter (CSE, ME, ECE, CE, Common).
   - Smooth, glitch-free Note Reader modal.

7. **Previous Year Questions (PYQs) Archive:**
   - GATE & semester papers for multiple engineering branches.

8. **Timed Engineering Mock Tests:**
   - Multi-choice quizzes with instant grading and in-depth explanations.

9. **Pomodoro Study Timer:**
   - 25m Focus, 45m Deep Work, 60m Sessions, and 5m Break presets.
